# Resources

## Open Source Topics

- **Open source basics**: licenses (MIT/Apache/GPL), what “free” means, maintainers vs contributors
- **Git fundamentals**: clone, branch, commit messages, rebase vs merge, resolving conflicts
- **GitHub workflow**: forks, issues, pull requests, reviews, approvals, CI checks
- **Finding beginner issues**: `good first issue`, `help wanted`, triage and reproduction
- **Documentation contributions**: READMEs, tutorials, FAQs, troubleshooting guides
- **Bug reports**: writing minimal repro steps, expected vs actual behavior, logs/screenshots
- **Code contributions**: small fixes, refactors, tests, performance improvements
- **Testing in OSS**: unit/integration/E2E, writing tests for existing behavior, avoiding flakes
- **Code review etiquette**: giving/receiving feedback, asking clarifying questions, suggested changes
- **Release process**: changelogs, semantic versioning, tags, GitHub releases
- **Project maintenance**: issue labeling, contributor guidelines, templates, security policy
- **Community & governance**: codes of conduct, moderation, community roles
- **Security in OSS**: responsible disclosure, dependency vulnerabilities, secret scanning
- **CI/CD basics**: GitHub Actions, linting/formatting, build/test pipelines
- **Open source project hygiene**: formatting, linters, type checks, commit conventions
- **Communication**: writing proposals (RFCs), design docs, discussion threads
